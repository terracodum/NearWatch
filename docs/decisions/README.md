принято осознанно, а не унаследовано из первоначального плана.

## Формат

Контекст, решение, последствия, открытые вопросы. Решение не правят
задним числом: если оно меняется, старое помечается «пересмотрено», а
новое оформляется отдельным ADR со ссылкой на него.
