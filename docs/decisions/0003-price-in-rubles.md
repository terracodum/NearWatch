# ADR 0003: цена в целых рублях

Статус: принято (Этап 1).

## Контекст

Исходный README хранил цену в копейках (`int64`). Маркетплейс, на
котором основан проект, показывает целые рубли.

## Решение

`price` хранится как `int64` в целых рублях. Тип колонки `bigint`
не меняется. Пример: `55000`, а не `5500000`.

## Почему

Главное правило осталось: деньги не хранятся во `float` (ошибки
округления). Копейки в предметной области не нужны, а конвертация на
границе API добавляет путаницу.

## Последствия

- Дробные суммы и другие валюты потребуют сменить единицу хранения
  (новая миграция и ADR).
- Обновлены README, [schema.md](../schema.md), [stage-1.md](../stage-1.md).
- Миграции не менялись.
